# Changelog

All notable changes to the **UT Pocket-Calculator** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - Initial Release

### Added
- **Core Engine:** Fast mathematical calculation processing for basic arithmetic operations.
- **UI/UX:** Responsive display layout utilizing digital segment typography (`DSEG7Classic`).
- **Localization:** Full multi-language support (English, Dari/Persian, Pashto).
- **Branding & Assets:** Custom app iconography and adaptive layout themes across high-density devices.
